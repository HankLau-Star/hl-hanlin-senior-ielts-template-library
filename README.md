# 刘涵的雅思模板库

> **Hank Lau’s IELTS Template Library · hanklau**

这是刘涵的个人雅思学习与复习网站，包含听力、口语、阅读和写作四大模块，以及可持续补充的中英文模板、真题索引、复习笔记与训练结构。

## 主网站

**在线访问：** [https://ieltstemp-ndtjnysa.manus.space](https://ieltstemp-ndtjnysa.manus.space)

## 当前模块

| 模块 | 内容 |
| --- | --- |
| 听力 | 四个 Part 的策略、信号词、同义替换、词汇检索与 Cambridge 笔记 |
| 口语 | Part 1 人设系统、Part 2 四张母题卡、Part 3 逻辑链与公开练习题索引 |
| 阅读 | 题型策略、判断题规则、逻辑信号、词汇检索与 Cambridge 笔记 |
| 写作 | Task 1 图表模板与公开题目索引；Task 2 四种题型与两套母模板 |

## 技术说明

项目采用 React、TypeScript、Vite，并已升级为可扩展的全栈架构。后续可在服务端安全接入口语训练 AI、个人练习档案与学习记录。

## 本地运行

```bash
pnpm install
pnpm dev
```

## 维护说明

所有个人模板、题库索引与学习笔记均可在 `client/src/lib/` 和对应页面组件中继续维护。公开网络题目仅作为练习索引使用，并应保留来源与版权边界。
