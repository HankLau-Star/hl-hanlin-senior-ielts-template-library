# 公开小作文 Task 1 题目索引：来源与使用边界

## 结论

Academic Writing Task 1 要求描述视觉信息；British Council 的公开页面将其界定为 graph、table、chart 或 diagram，要求至少 150 词并建议在约 20 分钟内完成。公开练习网站则覆盖柱状图、折线图、表格、饼图、流程图和地图等主要类型。网站将导入 **公开练习题的简短索引**，并标注图表类别、静态/动态图分类、模板方向和来源链接；不会批量爬取或复制完整剑桥出版套题、图表图片或受限题卡。

## 公开来源

| 来源 | 可用内容 | 网站处理方式 |
| --- | --- | --- |
| British Council：Free IELTS Academic Writing Practice | 官方样题与 Task 1 考试形式说明 | 记录官方任务类型与样题来源链接 |
| IELTS Liz：Sample Charts for Task 1 Practice | 公开练习图表与类别说明 | 使用简短、改写的练习题索引，标注图表类型与源站 |

## 分类规则

| 模板方向 | 图表类型 |
| --- | --- |
| 动态图 / Dynamic | 折线图、带年份的柱图/表格/饼图、变化地图 |
| 静态图 / Static | 单年或无时间变化的柱图、饼图、表格、组合图 |
| 地图与流程 / Maps & Process | 地点变化图、制造/自然过程图 |
